作业框架分析

光线追踪和之前的光栅化是两种不同的成像方法，框架上也有一些区别，看一下这次光线追踪的作业框架吧~

物体类 (Object、Sphere、MeshTriangle)

Object.hpp 中的 Object 类定义了物体的一些基本性质：

其中：

  1. specularExponent 高光系数、Kd 和 Ks，都是 Blinn-Phong 模型中见过的参数
  2. diffuseColor 漫反射的固有颜色
  3. ior 折射率，Index of Refraction
  4. materialType 材质类型，MaterialType 定义在 global.hpp 中，包括：
    • DIFFUSE_AND_GLOSSY，漫反射 + 高光的材质，就是 Blinn-Phong 渲染出的样子
    • REFLECTION_AND_REFRACTION，有反射 + 折射，透明材质
    • REFLECTION ，纯反射的，镜面材质

Sphere.hpp 中继承 Object 类实现了 Sphere 类，看下 intersect 和 getSurfaceProperties 两个函数。

  1. intersect 接收光线的 orig、dir (r⃗=o⃗+td⃗\vec{r} = \vec{o} + t\vec{d}r=o+td)，如果光线与球相交，就将 ttt 存入 tnear 作为第一个交点的位置并返回 true
  2. getSurfaceProperties 接收交点位置，返回该处的法向量，后续会被用于求反射、折射之类

Triangle.hpp 中的 MeshTriangle 类是用三角形网格表示的模型了。

场景类 (Scene)

Scene.hpp 中的 Scene 类有如下成员：

其中：

  1. width、height 是最终生成图像的尺寸
  2. fov 相机垂直张开的视角大小，渲染时会用到
  3. maxDepth 是光线在场景中弹射的最大次数
  4. epsilon 挺有趣。计算折射、反射等光线后，由于浮点数精度误差，可能弹射后的光线在原地又折射、反射一次 (Self-intersection 问题)，所以要将弹射后光线的起点沿法线偏移一小段 (epsilon)，避免这种问题
  5. objects 和 lights 存放物体和光源的对象

光线追踪渲染器 (Renderer)

课上我了解了 Recursive Ray Tracing 的大体过程，但是并不清楚一些细节，比如：

  • 什么材质会发生反射、折射
  • 反射、折射时光强要如何变化
  • 多个弹射点的性质要如何结合到一起，来给一个像素着色

以及其他的疑惑，比如：

  • 光追渲染器和光栅化渲染器的整体流程有什么区别，表述成模型大概是什么样的
  • 阴影是怎么做出来的，而且还是分两层的阴影
  • 背景是怎么加进去的，透明球上还能看到背景色

因此看一下 Renderer.hpp/cpp 的代码是有必要的…emmm 尽管不懂也不耽误写作业…但是学自己感兴趣的东西还是完美主义一些叭~

整体来看：

  1. void Renderer::Render() 是最顶层，会沿每个像素的方向发射一条光线，然后调用 Vector3f castRay() 获得像素颜色
  2. Vector3f castRay() 调用 std::optional<hit_payload> trace() 计算光线与物体相交的第一个交点，然后对 3 种不同材质采取不同做法
  3. std::optional<hit_payload> trace() 可求光线与场景中物体的第一个交点，返回 struct hit_payload 提供交点信息
  4. 最后是工具函数 Vector3f reflect()、Vector3f refract() 和 float fresnel()，分别用来算反射后方向、算折射后方向以及算折射 + 反射的能量分配

不同材质的处理：

castRay() 中

  1. REFLECTION_AND_REFRACTION，透明材质，递归继续追踪反射、折射光，按能量比例将两者返回的颜色相加
  2. REFLECTION，镜面材质，递归追踪反射光，将反射光颜色乘以能量损失就结束
  3. DIFFUSE_AND_GLOSSY，Blinn-Phong 模型，根据固有色，与光源连线计算

…所以也不是每个弹射点都要与光源连线…

背景色：

光线没有与物体相交而是射向了远处，就用背景色。透明球上会有背景色也是因为折射光线射向了远处。

阴影：

地面上可以看到 2 层阴影。对于 DIFFUSE_AND_GLOSSY 材质，castRay() 会将光线射到的位置与光源连线，中间没有其他物体就加上光源的光照，有物体遮挡就不加。

这个阴影挺粗糙，首先 2 个光源全被挡住的地方全黑了；然后由于做阴影时 “有遮挡就不算光源” 的处理，透明球、普通球的阴影效果是一样的，但按理说透明球肯定有光透过，阴影应该亮一些。
